# Outside Lands 2026 render pack

The card art is drawn as canvas vectors so it stays crisp at shelf and export sizes. `debug-photo.svg` is a neutral local-only harness image; it contains no artist identity. Licensed theme fonts may be added as `display.ttf` and `hand.ttf`. The server renderer explicitly registers those stable paths and falls back to the theme's system-safe font stack when they are absent.
