# Shared contracts

Every path codes against this file. It is the only thing that lets eight branches move in parallel without waiting on each other.

**Frozen at T+30 (1:30 PM).** After that, a change requires announcing it to everyone downstream. Adding an optional field is fine. Renaming or removing one is not.

Canonical location in code: `lib/types.ts` (owned by path 4). This document and that file must agree; if they drift, `lib/types.ts` wins and someone updates this doc.

---

## Conventions

- **Timestamps** are `number`, epoch milliseconds, UTC. Never strings, never `Date` objects across a boundary.
- **Coordinates** are `[lat, lng]` tuples or `{lat, lng}` objects — the tuple form is used inside polygons only. Order is always latitude first. Getting this backwards puts Golden Gate Park in Antarctica.
- **IDs generated on the device** are `clientId` — a UUID v4 minted at write time in IndexedDB. Every ingest is idempotent on `clientId`, so a retry never double-writes.
- **IDs generated by Convex** are `_id`. Client code never invents one.
- **Null is a valid answer** for stage and set resolution. It means "not at a stage" — in transit, at Wine Lands, at a food vendor. Do not coerce it to a default.

## 1. Core types

```ts
// lib/types.ts

export type LatLng = { lat: number; lng: number };
export type PolyPoint = [lat: number, lng: number];

export type StageId = string;
export type SetId = string;

export interface Stage {
  id: StageId;
  name: string;               // "Lands End" | "Twin Peaks" | "Sutro" | "SOMA" | "Duboce Triangle"
  polygon: PolyPoint[];       // closed implicitly; first point need not repeat
  bufferMeters: number;       // 20–45; Duboce Triangle is 45 (eucalyptus GPS drift)
  centroid: PolyPoint;        // used for the overlap tie-break
}

export interface SetRecord {
  id: SetId;
  stageId: StageId;
  artistName: string;
  startTime: number;          // epoch ms
  endTime: number;            // epoch ms
  slotIndex: number;          // 0 = opener of the day on that stage
  isHeadliner: boolean;
  estimatedAudience: number | null;
  isFestivalDebut: boolean;
  isFinalShow: boolean;
  genreTags: string[];
  jambaseArtistId: string | null;
  spotifyId: string | null;
  nextTourDate: { date: number; venue: string; city: string } | null;
}

export interface Grid {
  festivalId: string;
  eventName: string;          // "Outside Lands 2026"
  timezone: string;           // "America/Los_Angeles"
  fetchedAt: number;
  stages: Stage[];
  sets: SetRecord[];
}
```

The whole `Grid` for a three-day festival is a few hundred KB. It is fetched once, cached whole, and held in memory on the phone. **Never call JamBase per photo.**

## 3. Geometry and resolution (path 2 publishes)

```ts
// lib/geo/resolve.ts

/** Ray-cast point-in-polygon, buffer-aware. Returns null when at no stage. */
export function resolveStage(pt: LatLng, stages: Stage[]): StageId | null;

/** True if pt is inside poly. Pure; no buffer applied. */
export function inPolygon(pt: LatLng, poly: PolyPoint[]): boolean;

/** Metres between two coordinates (haversine). */
export function distanceMeters(a: LatLng, b: LatLng): number;

/** The set running on `stageId` at `ts`, honouring the grace window. */
export function lookupSet(
  stageId: StageId,
  ts: number,
  grid: Grid,
  graceMs?: number,          // default 15 * 60_000
): SetId | null;

/** Convenience: coordinate + time straight to a set. */
export function resolve(pt: LatLng, ts: number, grid: Grid): {
  stageId: StageId | null;
  setId: SetId | null;
};
```

**Overlap rule:** if a point falls inside two buffered polygons, resolve to the nearer centroid. Deterministic, never nondeterministic.

**Grace window:** ±15 minutes around a set window counts as "during the set" for mint eligibility. Dwell arithmetic uses the *unpadded* window.

## 4. Dwell (path 5 publishes)

```ts
// lib/dwell/runs.ts

export interface DwellRun {
  stageId: StageId;
  setId: SetId | null;
  startTs: number;
  endTs: number;
  dwellSeconds: number;
  completionRate: number;     // dwellSeconds / set duration, clamped to [0,1]
  sampleCount: number;
}

export function buildDwellRuns(
  samples: DwellSample[],
  grid: Grid,
  opts?: { maxGapMs?: number; minSamples?: number },  // defaults 5*60_000, 2
): DwellRun[];

export interface DerivedSignals {
  totalDwellSeconds: number;
  setsAttended: number;               // runs ≥ 10 min
  concurrentSetsSkipped: number;      // the opportunity-cost number
  perSetSkipped: Record<SetId, number>;
  completionRateAvg: number;
  fullSetCount: number;               // completionRate ≥ 0.8
  stageDiversity: number;             // distinct stages visited
  nightRatio: number;                 // share of dwell after 7PM local
  discoveryRate: number;              // share of sets with no prior card
  longestRun: DwellRun | null;
  topArtistBySetTime: { setId: SetId; artistName: string; dwellSeconds: number } | null;
}

export function deriveSignals(
  runs: DwellRun[],
  grid: Grid,
  priorArtistNames: string[],
): DerivedSignals;
```

**Gap rule:** a gap over 5 minutes between consecutive samples closes the run. Never interpolate across it — inventing presence you did not observe violates the core invariant.

### Thresholds

| Purpose | Threshold |
|---|---|
| Card mint eligible | ≥ 5 min in polygon during set window |
| Counted as "attended" for Wrapped | ≥ 10 min |
| Counted as "stayed for the whole set" | ≥ 80% of set duration |

## 5. Mint (path 6 publishes)

```ts
// lib/mint/eligibility.ts

export type CardState = 'LOCKED' | 'AVAILABLE' | 'SPINNING' | 'MINTED';

export type FrameVariant =
  | 'ranger_badge'
  | 'trail_marker'
  | 'fog_layer'
  | 'disco_bison'
  | 'field_notes';

export interface Mintable {
  setId: SetId;
  stageId: StageId;
  artistName: string;
  photoClientId: string;      // the photo that will become the card face
  dwellSeconds: number;
  rarityScore: number;        // 0..1
  state: CardState;
}

export function checkEligibility(args: {
  stageId: StageId | null;
  setId: SetId | null;
  dwellSeconds: number;
  hasPhotoInWindow: boolean;
  alreadyMinted: boolean;
}): CardState;

export function pickFrameVariant(set: SetRecord, rarityScore: number, seed: string): FrameVariant;
export function rarityScore(set: SetRecord, ctx: { concurrentHeadlinerRunning: boolean }): number;
```

All five eligibility conditions are required: inside polygon, during window ±15 min, dwell ≥ 5 min, at least one photo in the window, and no existing card for that `(user, set)` pair.

`AVAILABLE` **persists**. Leaving without spinning does not forfeit the card.

## 6. Card render (path 7 publishes)

The slot contract. Path 7 can build every frame before any real data exists, because this is all it needs.

```ts
// lib/render/types.ts

export interface CardRenderInput {
  photoUrl: string;            // object URL, data URL, or remote URL
  frameVariant: FrameVariant;
  artistName: string;
  stageName: string;
  dateLabel: string;           // "Fri Aug 7"
  setWindowLabel: string;      // "7:40 – 8:55 PM"
  dwellLabel: string;          // "47 min"
  rarityScore: number;         // 0..1; rarity mark drawn only above 0.7
  themePack: string;           // "outside-lands-2026"
}

/** Client-side canvas render for the shelf. Card ratio 5:7, 2x for retina. */
export function renderCard(
  input: CardRenderInput,
  canvas: HTMLCanvasElement,
  scale?: number,
): Promise<void>;

/** Server-side strip render. 12 frames across 3 days, one shareable image. */
export function renderStrip(cards: CardRenderInput[]): Promise<Buffer>;
```

Layer order is fixed:

```
layer 0  photo        (cover-fit, cropped to 5:7)
layer 1  treatment    (grain, wash, fog gradient — variant-specific)
layer 2  chrome       (border, badge shape, theme pack art)
layer 3  text slots   (artistName, stageName, date, setWindow, dwell)
layer 4  rarity mark  (only if rarityScore > 0.7)
```

Frames are **layered templates with slots, never baked images.** Frames are applied at *render* time, not capture time, so themes can improve without invalidating captured photos.

## 7. AI (path 8 publishes)

Everything here sits **beside** the fact path, never inside it. The model describes; it never locates.

```ts
// lib/ai/vision.ts
export interface VisionResult {
  bestFrameId: string;
  photos: Array<{
    id: string;
    subject: 'stage' | 'people' | 'food' | 'scenery';
    quality: number;          // 0..1
    blurred: boolean;
  }>;
}
export function classifyBurst(photos: { id: string; dataUrl: string }[]): Promise<VisionResult>;

// lib/ai/narrative.ts
export function writeWrapped(stats: DerivedSignals & { extras: Record<string, unknown> }): Promise<string[]>;

// lib/ai/taskCopy.ts
export function writeTaskCopy(intent: string, set: SetRecord): Promise<{ description: string; rewardFraming: string }>;
```

Vision prompts must specify JSON only, no preamble, no markdown fences — **and parse defensively, stripping fences anyway.**

Narrative system-prompt constraints, non-negotiable:
- Never compute, infer, or estimate a number. Use only the numbers given.
- Descriptive, not evaluative. State what happened; let it become a character.
- No flattery. The lines that land are the ones that sting slightly.
- Second person, present tense where possible.
- One sentence per card. No preamble.

## 8. Convex API surface (path 4 publishes)

Function names are frozen. Signatures may gain optional args.

### Mutations
```ts
api.ingest.photos({ userId, eventId, photos: PhotoUpload[] })        // idempotent on clientId
api.ingest.samples({ userId, eventId, samples: SampleUpload[] })     // idempotent on clientId
api.mint.claim({ userId, setId, photoClientId, frameVariant })       // → cardId; dedupes on (userId,setId)
api.tasks.verify({ userId, taskId })                                 // → completion | null
api.wrapped.compute({ userId, eventId })                             // → wrappedId
```

### Queries (reactive — these drive the UI live)
```ts
api.queries.grid({ eventId })                     // → Grid
api.queries.shelf({ userId })                     // → Card[]
api.queries.mintableNow({ userId, lat, lng })     // → Mintable[]
api.queries.taskProgress({ userId })              // → TaskProgress[]
api.queries.wrapped({ userId, eventId })          // → Wrapped | null
```

### Tables

```

                 startTime, endTime, slotIndex, isHeadliner, estimatedAudience,
```

### Indexes that matter
- `photos` by `(userId, timestamp)` — resolution scan
- `dwellSamples` by `(userId, timestamp)` — run grouping
- `cards` by `(userId, setId)` — dedupe on mint
- `sets` by `(eventId, stageId, startTime)` — the grid lookup

## 9. The one rule that outranks the contracts

**Deterministic code decides what happened. The model only writes the sentence around it.**

If a fact cannot be derived from a coordinate and a timestamp, it does not appear in the product. Any code that lets a model decide *where* or *when* something happened is wrong and gets reverted, no matter how good the demo looks.
